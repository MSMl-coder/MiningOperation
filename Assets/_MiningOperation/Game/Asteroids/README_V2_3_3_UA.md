# Mining Operation — Environment Generator v2.3.3

## Основне ігрове правило
Газ у Mining Operation НЕ видобувається з газових хмар. Газ як товар/ресурс буде ВИРОБЛЯТИСЯ у майбутній системі промисловості/переробки (не реалізовано в цьому модулі). `Gas` Spawn Point створює тільки візуальну космічну туманність. Він не має газових запасів, `ExtractGas`, розрахунку видобутку, складу газу чи фізичних колайдерів.

## Що нового
- Детерміновані візуальні записи газових хмар (`schemaVersion=2`), без будь-яких полів маси або ресурсів.
- Сумісність із JSON v2.3.x: старі схеми `schemaVersion=1` завантажуються, їхні `initialMassKg`, `remainingMassKg`, `gasResourceId` ігноруються. При новому збереженні цих полів немає. **Старі газові запаси не переносяться у виробничий інвентар.**
- Більш об'ємний вигляд завдяки трьом шарам м'яких частинок: внутрішньому, середньому й зовнішньому. Це **pseudo-volume**, а не volumetric raymarching.
- Легкий повільний рух через Particle System Noise; параметр `Gentle drift` вимикається значенням `0`.
- Нова 512×512 м'яка газова текстура зі згасанням на краях, без тайлінгу, створюється в редакторі.
- Новий матеріал `MO_GasSoftVolume_v233.mat` на основі **Universal Render Pipeline/Particles/Unlit**; користувацькі матеріали зберігаються. Попередній стандартний `MO_Gas_URP.mat` оновлюється після запуску інсталятора.
- `Asteroid Field Studio` більше не показує Gas Resource ID, Initial Gas Mass і кнопки, пов'язані з виснаженням. Реконструкція газової формації змінює лише її вигляд.
- Тести газової підсистеми переписано під візуальний, невидобувний сценарій.

## Оновлення з v2.3.2
1. Створити коміт або резервну копію проєкту. Вийти з Play Mode.
2. Розпакувати `PATCH` і скопіювати його папку `MiningOperation_Asteroids/` поверх `Assets/_MiningOperation/Game/Asteroids/` з відповідним збереженням директорій `Runtime/`, `Editor/`, `Tests/`. Не видаляти старі `.meta` та `.asset` файли.
3. Дочекатися компіляції Unity 6.
4. Відкрити **Tools → Mining Operation → Asteroid Field Studio**.
5. Вибрати існуючий Gas Spawn Point → вкладку `VISUALS` → **Install / Repair Ice & Gas Assets** (створиться нова текстура та оновиться стандартний газовий матеріал).
6. В `VISUALS` налаштувати `Puffs per cluster`, `Opacity`, `Layer irregularity` та `Gentle drift`, після чого натиснути **Apply Cloud Appearance**.
7. Для нової локації створити Spawn Point → `Type: Gas`, встановити число кластерів та розмір у `LOCATION` → `Refresh Preview` → **BUILD CLOUD VISUALS**.
8. Запустити Play Mode. Перевірити, що газові поля не породжують астероїдні GameObject та не впливають на ресурси.

## Рекомендовані параметри для тесту
- Cloud clusters: 5
- Cloud radius: 850 m
- Puffs per cluster: 72 (пізніше 96 при достатньому FPS)
- Opacity: 0.18
- Layer irregularity: 0.35
- Gentle drift: 0.32 (0 для максимального FPS)

## Збереження
`MOGasFieldRenderer.CaptureJson()` тепер зберігає **лише візуальну форму**, але зазвичай газову формацію можна повністю відтворити за seed і параметрами Spawn Point. Збереження основних астероїдів (`AsteroidFieldSnapshot`) і льодових ресурсів не змінено.

## Обмеження / перевірки
- Не створюється повноцінний фізичний об'єм із raymarching, світловим розсіюванням чи 3D density texture. Це багатошарова прозора Particle System.
- Шейдери, імпорт assets, коректність частинок, збереження сцени та FPS потрібно перевірити у **Unity 6 URP**, якого немає в середовищі складання.
- Модуль виробництва газу для станції НЕ доданий: потрібно пізніше окремо спроєктувати виробничі рецепти, потужності, витрату енергії, інвентар і логістику.
