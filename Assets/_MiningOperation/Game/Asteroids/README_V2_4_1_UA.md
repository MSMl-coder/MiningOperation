# Mining Operation Environment Generator v2.4.1

Фокус версії: **прибрати “мильний / розмитий” вигляд астероїдів**.

## Що змінено
- V5-геометрія астероїдів тепер має жорсткіші smoothing groups на різких переломах, кратерах і сколах.
- Посилено саму геологію: кратери глибші, краї виразніші, додано внутрішні губи/тераси.
- Для кам'яних астероїдів стабільний runtime тепер **спершу намагається використати `Mining Operation/Asteroid Rock URP`**, а якщо shader недоступний — автоматично падає назад на `URP/Lit`.
- Підкручено параметри кам'яної поверхні: більше cavity/detail, сильніший micro relief, вищий normal strength.
- Імпорт rock-текстур тепер допускає `maxTextureSize = 2048`, `aniso = 8`.

## Важливо
Щоб побачити ефект на старих полях, **перебудуй / regenerate** астероїди. Якщо сцена показує кешовані старі mesh-дані, нові creased normals і оновлена геологія не з’являться.

## Рекомендований порядок після імпорту
1. Імпортуй PATCH або FULL.
2. Відкрий `Field Studio`.
3. Перебудуй belt / regenerate asteroids.
4. Якщо потрібно — ще раз застосуй `Rock Material Setup` / інсталяцію surface textures.

## Очікуваний результат
- менше “замилювання” на силуеті;
- чіткіший рельєф кратерів;
- кращий мікрорельєф на поверхні;
- кращий close-up без явного тайлінгу.
