# v2.3.3 — Visual Gas Only

- Gas = космічне візуальне середовище, а не родовище. Газ як продукція з'явиться пізніше в незалежній виробничій системі.
- Видалені `gasResourceId`, `estimatedGasMassKg` зі Spawn Point та `ExtractGas` із газового Renderer.
- Видалені масові поля із нових записів газових хмар і JSON.
- JSON v1 gas layouts імпортуються як візуальні дані з міграцією в схему 2; застарілий ресурсний баланс не переноситься.
- Генерація позицій повністю відтворюється з seed, а налаштування кольору/потоку не змінюють структуру поля.
- Багатошарові billboard cloud wisps і контрольоване легке переміщення частинок.
- 512px безшовна на краях текстура м'якої хмари, новий стандартний URP particle material.
- Одне вікно Field Studio; для Gas прибрано логіку ресурсів і змінено тексти кнопок.
- Переписані регресійні EditMode-тести для невидобувного газу.
