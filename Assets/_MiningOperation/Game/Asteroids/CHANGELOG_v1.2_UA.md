# Mining Operation — v1.2: EVE-style Asteroid Field Generator

Побудовано на повному Asteroid Generator v1.1 без зміни його публічних API, форматів індивідуальних астероїдів та алгоритму геометрії v2.

## Додано

- **Шість формацій:** CrescentBelt, BrokenBelt, BrokenRing, ClusterGroups, Stream, SphericalCloud.
- **Field Studio** в Unity Editor: 2D-попередній перегляд без створення мешів, прогноз класів, генерація в сцені, прогрес та скасування.
- **Детерміноване розміщення:** ID поля, `fieldSeed`, індивідуальні ID, позиції та обертання.
- **Швидка перевірка проміжків:** просторове хешування замість перевірки кожної пари астероїдів при пошуку розміщення.
- **Повний persistent snapshot:** фізичні параметри, класи, список ресурсів, залишкова маса та позиції кожного астероїда.
- **Поступова генерація:** `BuildStep`, CPU-бюджет на кадр для розрахунку ресурсних записів.
- **Стрімінг візуальних астероїдів:** дистанція появи та зникнення, обмеження GameObject і мешів.
- **Фоновий видобуток:** `ExtractResourcesById` без активного GameObject.
- **EditMode тести** для формацій та збереження.

## Що не включено

Колектори, геймплей видобутку, навігація кораблів, регенерація родовищ, Save Manager слотів і GPU instancing.

## Сумісність

Вихідні C# v1.1 збережені. Новий формат **AsteroidFieldSnapshot schemaVersion 1** окремий від JSON окремих астероїдів. Для існуючих полів v1.2 після регенерації формації потрібен новий snapshot.

**Стан перевірки:** базовий статичний аудит і ZIP integrity check; запуск у Unity 6 не підтверджений.
