# Mining Operation — Asteroid & Environment Generator v2.3

## Призначення
Єдине Unity Editor вікно для трьох типів процедурних локацій:

- **Rock** — стандартні астероїди, ID, класи I–III, ресурси, LOD і потоковий рендеринг v2.2.1.
- **Ice** — такі самі видобувні астероїди зі збереженням ID/LOD, але окремими ресурсами, густиною, профілем геометрії та матеріалом URP/Lit.
- **Gas** — об'ємні візуальні скупчення із детермінованими центрами й запасами газу, один Particle System renderer на Spawn Point.

Це стилізація за мотивами холодного середовища й газових туманностей Homeworld 3; це **не** повноцінний raymarching volumetric renderer.

## Встановлення
1. Збережіть проєкт, зробіть Git commit/резервну копію. Unity має бути поза Play Mode.
2. Для оновлення v2.2.1 скопіюйте вміст папки `MiningOperation_Asteroids/` із **PATCH ZIP** у `Assets/_MiningOperation/Game/Asteroids/` поверх скриптів. Збережіть існуючі `.meta` файли.
3. Приберіть **два застарілі C#-файли та їх `.meta`**, якщо вони ще є в Editor: `AsteroidGeneratorStudio.cs` та `AsteroidField3DPreview.cs`. Їхні можливості тепер у Field Studio. Видалення інших файлів не потрібне.
4. Дочекайтесь перекомпіляції Unity 6 (URP).
5. Відкрийте **Tools → Mining Operation → Asteroid Field Studio**.
6. У вкладці **VISUALS** натисніть **Install / Repair Ice & Gas Materials**. З'являться готові матеріали, PNG текстури, Ice Resource Catalog і Ice Generator Settings у `Assets/_MiningOperation/AsteroidAuthoring/Visuals/`.
7. Виберіть Spawn Point зліва або створіть новий. Тип `Ice` або `Gas` задається у **LOCATION**.
8. Розставте точки у Scene View, скоригуйте поля та натисніть **Refresh Preview**. Прев'ю не змінює збереження.
9. Натисніть **BUILD / REBUILD · Save to Scene**. Для старих астероїдних полів підтвердження попередить про скидання їхнього стану видобутку.

## Новий інтерфейс
Є **одне редакторне вікно**, що містить:
- Ліва панель: список усіх Spawn Points у сцені, створення нової локації, Quick Start.
- `LOCATION`: тип локації, ID, seed, кількість і формація для Rock/Ice; кількість газових хмар і їхня палітра для Gas; вбудована карта та 3D-зразок астероїда.
- `SHAPE & QUALITY`: геологічні параметри та бюджети LOD/streaming.
- `VISUALS`: матеріали, рух, декоративні уламки, налаштування неба/освітлення.
- Фіксована нижня смуга: статус збереження та одна основна кнопка побудови.

Замість довгого Inspector Spawn Point має лише коротку інформацію й кнопку відкриття Field Studio.

## Льодові астероїди
Відповідні нові поля отримують окремий `MO_IceGenerator` з профілем геометрії (виразніші злами, спокійніший мікрорельєф). Ресурсний каталог містить водяний лід, гідратовані силікати, аміачний/метановий лід та умовні рідкісні кріомінерали. Це **ігрова** модель складу, без внутрішніх покладів чи фізичного розтріскування.

Збереження Rock (тип 0) залишаються Rock. Для Ice тип поля записується у той самий JSON snapshot, схема збереження залишається v1. Після `LoadJson()` тип відновлюється автоматично.

## Газові скупчення
`MOGasFieldRenderer` має методи:
- `BuildRecords()` — створити детерміновані хмари за Spawn Point seed, перезаписує запаси газу **лише за явною командою**.
- `CaptureJson()` / `LoadJson(string)` — окреме збереження газових відкладів.
- `ExtractGas(string cloudId, double requestedKg)` — символічне видобування із хмари за ID, повертає фактично видобуту масу.
- `RebuildVisuals()` — відновлення одного Particle System (не створює GameObject на кожен puff).

Газ не є «всередині астероїда», не має геометричних областей залягання; запис хмари містить центр, радіус і масу газу. У майбутньому можна підключити корабельні газозбирачі. На v2.3 газова картинка — атмосферний спрайтовий об'єм, без реального поглинання світла, датчиків і об'ємної фізики.

### Ліміти за замовчуванням
- 5 хмар на Spawn Point.
- 72 м'які напівпрозорі спрайти на хмару, максимум 20 × 200.
- Текстура газу 256² RGBA, один спільний матеріал URP/Particles/Unlit.
- Льодова текстура 512² RGBA, горизонтально зациклена для UV-шва, без UV tiling.

Це **цільові конфігурації**, а не виміряний FPS.

## Сумісність та обмеження
- Існуючі rock записи, resource IDs та параметри геометрії не перегенеровуються автоматично.
- Якщо перевести Rock Spawn Point у Gas, старий астероїдний snapshot буде збережений, але його рендеринг вимкнеться. Для видалення є окрема підтверджувана кнопка **Clear obsolete rock snapshot...**.
- Газові JSON записи мають **власний** API збереження; інтеграцію з головним Session Save Manager наразі не зроблено.
- Для великих плавучих льодових мас із Homeworld 3 у майбутньому потрібен спеціалізований генератор льодових мегаструктур; поточні Ice Field — астероїди з окремим виглядом і складом.
- Shader names залежать від активного URP. Якщо URP/Particles/Unlit або URP/Lit не знайдено, installer зупиняється з діагностикою замість збереження рожевого матеріалу.
- Фактична компіляція, GPU/Metal рендеринг та профілювання в Unity 6 не виконувалися в цьому середовищі. Запустіть EditMode-тести після імпорту.
