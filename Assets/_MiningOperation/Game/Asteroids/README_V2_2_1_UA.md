# Mining Operation — Asteroid Generator v2.2.1 / Rock Surface & Motion

Цей пакет встановлюється поверх v2.2. Для наявного проєкту використовуйте PATCH, а не FULL. Коренева папка архіву `MiningOperation_Asteroids` відповідає `Assets/_MiningOperation/Game/Asteroids/`.

## Що змінено

- Замість 256×256 Perlin-texture з 3.5 повтореннями — імпортована **1K albedo + 1K normal**, на основі нерегулярної дрібної фактури. Обидва файли включені в пакет, **не генеруються під час Play Mode**.
- UV-координати мають **один оборот текстури** навколо астероїда. Для різних seed поворот проєкції різний. Стик 0/1 та полюси опрацьовуються розділенням візуальних вершин без зміни позицій.
- Нормальна карта за замовчуванням слабка (`0.18`), щоб прибрати «складки/пластилін». Контраст формують геометрія і світло.
- Рендеринг використовує **Universal Render Pipeline/Lit** за замовчуванням, без ризикового кастомного шейдера. Зберігається експериментальна опція для ручного тестування.
- Геологія V5 **для нових астероїдів**: менше дрібної геометричної хвилястості, рідкі виразніші ударні кратери. Геометрія V1–V4 відтворюється як раніше.
- Нові швидкості обертання, незалежні множники `mineableRotationMultiplier`, `decorativeRotationMultiplier` і старий master `rotationSpeedMultiplier`.

## Установка

1. Зробіть commit або резервну копію проєкту. **Вийдіть з Play Mode**.
2. Розпакуйте PATCH, скопіюйте **вміст** `MiningOperation_Asteroids/` у `Assets/_MiningOperation/Game/Asteroids/` зі збереженням `.meta` наявних скриптів. Нові текстури отримають власні `.meta` під час імпорту.
3. Дочекайтесь компіляції.
4. Відкрийте **Tools → Mining Operation → Asteroid Field Studio** і виберіть Field Settings.
5. Натисніть **Install Non-Tiling Rock Surface v2.2.1**. Це назначить 1024×1024 PNG, налаштує `NormalMap` і вимкне експериментальний шейдер.
6. Натисніть **Use Safe URP Rock Surface** (або перевірте, що `allowExperimentalRockShaders = false`).
7. Запустіть гру. Нові поверхні та швидкість обертання працюють з уже збереженими астероїдами. Для кратерів V5 створюйте **нові** астероїди; `Force Rebuild Field` перезаписує прогрес видобутку.

## Початкові значення

- Master rotation: 1.0x
- Mineable rotation: 1.0x (можна 1.5x для тестової сцени)
- Decorative rotation: 1.0x
- Rock normal: 0.18, рекомендований діапазон 0.12–0.28
- URP Lit Metallic: 0.0, Smoothness: 0.045

## Чому менше тайлінгу

Попередні UV множились на 3.5 і використовували 256px повторювану текстуру. Тепер UV охоплюють **одну** 1K карту з окремим поворотом проєкції для різних seed. UV-шов має дублікати однакових за позицією вершин, щоб уникнути протягування текстури через трикутник. Карта за своєю природою безперервна по горизонтальному стику; при цьому повна відсутність розтягнення біля полюсів без triplanar shader неможлива. Якщо при Game View з’являться смуги на полюсах, потрібен окремий валідаційний triplanar pass; заради стабільності поки залишено URP/Lit.

## Сумісність і обмеження

- ID, seed, ресурсні класи й кількість видобутої матерії залишаються без змін.
- Формат JSON не змінено; для **нових** астероїдів дозволено `generatorVersion=5`, старі 1–4 підтримуються.
- Візуальні вершини уздовж UV шва дублюються; це не збільшує масу й не змінює положення геометрії. Тест замкненості враховує збіжні позиції.
- Текстури PNG не вимагають інтернету чи сторонніх пакетів. Вони синтетичні; фотореалістичний результат, як у EVE, усе ще потребуватиме фізично реалістичних сканів/матеріалів та налаштування освітлення.
- **Unity 6 тут не запускався**. Потрібно перевірити компіляцію, текстурні імпортери, регресійні EditMode-тести й результат у Game View (зокрема UV біля полюсів та відображення нормалей на macOS/Metal).
